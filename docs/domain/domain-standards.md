# Domain Standards — Education

Alignment mapping for this core. *Aligned to* throughout.

## Concept mapping

| Platform concept | Domain standard | Mapping |
|---|---|---|
| Learning activity events | xAPI (IEEE 9274.1.1) | Events follow the actor–verb–object discipline; an LRS consumes them downstream |
| Enrolments & rosters | IMS OneRoster | Learner and program data posture |
| External tools | IMS LTI 1.3 | Integrated at the gateway; this core owns records, not launches |
| Credentials | Open Badges 3.0 / W3C Verifiable Credentials | The compliance evaluator produces completion verdicts that an issuer turns into credentials |
| Accessibility | WCAG 2.2 | Error/content contracts; adopter UIs remain responsible for their own conformance |

## Scope boundaries

This core is not an LMS and does not deliver content or proctor exams. It is the system
of record for learners, progress, assessment rules and completion evidence.
